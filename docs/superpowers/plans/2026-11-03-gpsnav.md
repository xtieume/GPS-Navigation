# GPSNav Implementation Plan

**Goal:** Build the jailbreak GPS spoofer described in SPEC.md.
**Architecture:** A UIKit/MapKit companion persists configuration; a SpringBoard engine advances the route or random position and publishes Darwin notification state; injected Core Location manager hooks substitute locations for eligible apps.
**Tech Stack:** Objective-C, Logos, C, Theos, MapKit, Darwin notify.
**Spec:** SPEC.md

1. Implement and test portable geographic calculations for distance, bearing, interpolation and random offsets.
2. Implement shared state, the SpringBoard engine and Core Location hooks.
3. Implement map selection, search, routes, saved items and settings in the companion app.
4. Add package metadata, scripts, documentation and CI; build and inspect both packages.
